# SHURA-01

Canonical SHURA embodiment.

## Concept

SHURA-01 is based on visual concept #3.

## Status

Active.

## Source

The `source/` directory contains canonical artwork and source references.

## Exports

The `exports/` directory contains runtime-ready assets.

## Emotions

The `emotions/` directory contains expression-development assets and experimental variants.

## Runtime contract

ProjectBEA currently expects each avatar mood to resolve to:

- idle
- talking

The runtime-compatible assets will therefore ultimately be exported into the `exports/` hierarchy.

## Current target

First functional milestone:

- normal idle
- normal talking

All other moods may temporarily fall back to normal.

## Future

SHURA-01 will eventually have a complete emotional expression set and potentially animated/Live2D/3D embodiment layers.
